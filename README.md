# 台股每日訊號

每個交易日收盤後（台北 15:35，18:30 補跑一次），GitHub Actions 自動：

1. 從證交所、櫃買中心公開資料補抓行情與月營收（不需 token）
2. 更新狀態檔（`data` 分支，只保留最新一版）
3. 算出買進候選、續抱/賣出條件，發布到 GitHub Pages 網頁

網頁上輸入自己的持股與現金（只存在自己的瀏覽器），就會列出明天要賣、要買的股票與股數，以及 00881 核心是否該調整。

## 策略（參數已驗證，請勿修改）
- 股票池：每季依近 60 日平均成交金額取前 500 檔（上市櫃滿 120 交易日、日均成交值 ≥ 1,000 萬）
- 買進：營收創 12 個月新高，且收盤突破前 60 日最高收盤；最多 7 檔、每檔總資產 10%
- 賣出：營收比前 12 個月最高低 20% 以上、股價距一年高點超過 15%，或離開股票池
- 核心：00881 佔 30%，每 20 個交易日調回（2026-10-28 起，原為 8 檔＋20%）

## 檔案
- `scripts/strategy.py`：計算與抓資料
- `scripts/update.py`：每日更新、產生 `signals.json`
- `web/`：網頁（可加到手機主畫面）
- `.github/workflows/daily.yml`：排程

個人研究工具，不是投資建議。
